# Realistic parameters for a reference LTA/LTAHP-CAES plant — sourced findings

Merge of seven parallel web-research passes, one per topic of
`artifacts/research/REALISTIC_PARAMETERS_BRIEF.md`. **Every value carries a source URL.**
No value was invented; where no credible public number exists the row says `not found`.
No other repository file was created, modified or deleted, and no test, build, formatter or
linter was run.

## How to read this file

| tag | meaning |
|---|---|
| `[datasheet]` | vendor / manufacturer document (brochure, product page, datasheet) |
| `[paper]` | peer-reviewed journal or conference paper |
| `[project]` | project-owner, operator or regulator document |
| `[engineering estimate]` | judgement or arithmetic derived from the cited source (basis stated) |
| `[not found]` | no credible public value located — stated rather than guessed |

*Link status:* every URL in this file was fetched and checked — 155 of 163 resolve. The eight
that do not are listed here rather than flagged row by row: MDPI `energies` (4 articles),
ScienceDirect (1) and Harvard Scholar (1) return HTTP 403 to automated clients while being
valid in a browser, and Ingersoll Rand and Energiforsk rate-limited the checker (429).
Three URLs that were genuinely dead at fetch time were replaced with resolvable equivalents
(Atlas Copco GT-Series page, Sarmast et al. via DOI, the ADELE brochure mirror), and two
dead links whose claim could not be verified were removed and the row marked instead.

**Independent cross-check.** The seven research passes were not taken on trust. The parent
agent re-read the load-bearing primary sources itself and the disagreements are shown in
§4/§5 rather than smoothed over: TNO 2020 R12006 Table 2.2, Succar & Williams 2008,
Budt/Wolf/Span 2012, Hadam & Budt KompEx 2023, Luo et al. 2016, Sciacovelli et al. 2017 and
the DWD CDC 1991-2020 station normals. See Appendix A for the ledger.

## 0. Simulator semantics that change how these numbers must be entered

These were confirmed by read-only inspection of `caes/config.py`, `caes/plant.py`,
`caes/logic.py`, `caes/heat_exchangers.py` and `caes/thermal_limits.py`. Four of them
contradict the natural reading of the input names, so a naive entry of the values below
would be wrong.

| input | what the simulator actually does | consequence |
|---|---|---|
| `compressor_efficiency` | **per-stage isentropic**, not polytropic (`caes/thermodynamics.py` `compress()`); the repo itself notes polytropic is the more honest constant to hold fixed | the vendor polytropic figures below must be converted before entry; the conversion table is in Appendix B |
| `intercooler_pressure_drop` | fraction of **stage inlet** pressure, and `_compression_ratio()` **divides by `(1 - drop)`** so the train still lands on `storage_pressure_bar` | with `n=6`, `drop=0.02`, `p=85.8 bar` the model's real per-stage ratio is 2.1383, not 2.0955; any external sanity check must use `2.0955/0.98` |
| `storage_duration_hours` | each tank's **standing time between charge and discharge** (`caes/logic.py`, `docs/05_CONFIGURATION_LOGIC.md`), applied to both tanks — *not* the plant's discharge duration | the brief's "typical storage duration" and this field are different quantities; both are tabulated in §5 |
| `thermal_storage_tank_ua_w_per_k` | a conductance **normalised per kg of air**, `UA_tank,physical / stored_air_mass`, not an absolute W/K (`caes/config.py`) | §5 gives the physical UA in W/K **and** the normalisation arithmetic |
| `cold_return_cooler_ntu` | atmosphere is an infinite capacity rate, so `eps = 1 - exp(-NTU)` | NTU is not comparable with the counter-flow NTUs elsewhere in the config |
| expander outlet floor (not an input) | hard envelope: **10 °C liquid-water floor**, or **local frost point + 10 K** when the boundary is below 0 °C (`caes/thermal_limits.py`, `EXPANDER_ICE_MARGIN_K = 10`) | the "is a near-0 °C outlet acceptable?" question in the brief is answered *no* by this model regardless of what a vendor tolerates; see §2.5 |

**Contents.** §0 semantics · §1 compressor · §2 expander · §3 heat exchangers ·
§4 LTA-CAES literature · §5 storage · §6 heat user · §7 site ·
[Recommended reference configuration](#recommended-reference-configuration) ·
[Open doubts](#open-doubts) · Appendix A cross-check ledger · Appendix B derived arithmetic.

**Headline corrections to the shipped defaults** (detail in the sections and in Open doubts):
`cold_return_cooler_ntu` 5.0 → **0.8** (5.0 is not physically achievable);
`thermal_storage_tank_ua_w_per_k` 0.006 in the example configs → **≈1e-3** per kg-air;
`storage_duration_hours` is a tank **dwell**, not a discharge duration.

The counter-flow relation used for every NTU conversion in this file is the inverse of
`caes/heat_exchangers.py:counterflow_effectiveness`:

```
eps = (1 - exp(-NTU (1 - Cr))) / (1 - Cr exp(-NTU (1 - Cr)))      Cr = Cmin/Cmax
NTU = ln((1 - eps Cr) / (1 - eps)) / (1 - Cr)
```

For orientation, the values recommended below map to effectiveness as follows (computed with
the repository's own function):

| NTU | eps at Cr=1.0 | Cr=0.5 | Cr=0.3 | Cr=0.1 |
|---|---|---|---|---|
| 0.8 | 0.444 | 0.475 | 0.486 | 0.500 |
| 3.0 | 0.750 | 0.874 | 0.911 | 0.939 |
| 5.0 | 0.833 | 0.957 | 0.979 | 0.990 |
| 8.0 | 0.889 | 0.991 | 0.997 | 0.999 |

## 3. Heat exchangers — NTU classes, approach temperatures and air-side pressure drops

Every NTU below is the counter-flow number of transfer units for the stated capacity-rate
ratio; the approach temperature that produced it is given so it can be re-derived. The
intercooler/interheater, heat-user and extraction NTUs are `UA/Cmin`; the dry-cooler NTU uses
the atmosphere as an infinite capacity rate (`eps = 1 - exp(-NTU)`).

### From the 4. LTA-CAES literature pass

## 8. Open doubts and unresolved questions

1. **Wolf & Budt 2014 has no engineering assumption table.** The single table (Table 1) is an economic scenario table. Per-exchanger pressure drops, isentropic/polytropic efficiencies, per-stage pressure ratios and per-stage temperature glide are all absent. Anyone quoting "the Wolf & Budt assumption table" for those quantities is quoting something else.
2. **The underlying assumption set is in an unobtainable German final report.** Both the Modelica paper and Hadam & Budt 2023 cite Doetsch, Budt, Wolf & Kanngiesser, "Adiabates Niedertemperatur-Druckluftspeicherkraftwerk zur Unterstuetzung der Netzintegration von Windenergie", final report FKZ 0325211, Oberhausen 2012. This report is the true source of the 51.98 / 56.31 / 59.07 % efficiency triple and of the 52.1 MW / 28.8 MW power pair. I found only bibliographic records (Projekttraeger Juelich research yearbook 2011 lists the grant, EUR 302 455, 01.09.2010-31.05.2012) - no full text. **Open doubt: obtain this report.**
3. **Budt et al. 2016 review (Applied Energy 170:250-268) is paywalled.** Its Table 1 ("Comparison of technical parameters for different CAES concepts") is very likely to contain the LTA-CAES / ADELE / Huntorf / McIntosh parameter summary that would close several gaps here. Only the Fraunhofer publica metadata page and third-party snippets were reachable. **Open doubt: obtain Table 1.**
4. **Scribd mirror for the Wolf & Budt 2014 full text.** Content verified as the published paper, but the retrieval path is not a scholarly host. A re-check against the Elsevier version of record is advisable before these numbers are frozen into documentation.
5. **Szablowski et al. 2017 could not be fetched directly.** The Warsaw University of Technology repository URL is behind a Cloudflare bot challenge. The per-exchanger pressure drops (0.1 / 0.25 bar) were read from the indexed full text of that same repository PDF. **Open doubt: confirm against the version of record (Energy 138:12-18).**
6. **Figures not digitised.** (a) Wolf & Budt Fig. 6 - break-even capital cost bars for 2008-2011 (only the textual 1210 EUR/kW_turb average is quoted). (b) Hydrostor Figures 3-6 - capex in US$/kW and US$/kWh (images, no numbers in text). (c) Wolf & Budt Fig. 2 - cycle efficiency versus storage temperature scatter, from which individual literature points could not be read reliably. (d) Tola et al. Figs. 3 and 7 - TES charge/discharge temperature profiles; the text quotes only the stable-state values (~520 / 500 / 460 degC at aspect ratios 3 / 2.5 / 2).
7. **Disagreement between sources on the same quantity, flagged rather than reconciled.** LTA-CAES RTE: 54-67 % (2012 conference version) versus 52-60 % (2014 journal version) versus 55.53 % (KompEx 2023). 6. **LTA-CAES designs are built at 100–152 bar, not at the 60 bar recommended here.** The 60 bar
   screening value is anchored on *operating* caverns and on the throttled expander inlet both
   legacy plants run at; the LTA-CAES literature (Budt/Wolf/Span 2012, KompEx, Olympios et al.)
   designs at 40–152 bar. Choose deliberately, because the choice moves the stage count, the
   per-stage ratio and the intercooler pressure drops together.
