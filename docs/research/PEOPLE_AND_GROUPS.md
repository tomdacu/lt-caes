## Software and reference projects

| Project | Relevance |
|---|---|
| [CASSI](https://cas-si.org/) | Flexible Fortran CAES plant simulator supporting multi-stage plants, quasi-steady/dynamic operation, load curves, and external TES models. It is a useful benchmark for architecture and model scope. |
| [CoolProp](https://coolprop.org/) | Thermophysical-property library used by this repository for real-air properties. |
| [IEA Energy Storage - CAES fact sheet](https://www.iea-es.org/wp-content/uploads/public/FactSheet_mechanical_CAES.pdf) | Technology-level reference for the wider CAES landscape. |

## Reading these sources responsibly

These researchers and tools provide useful comparison points, not validation of
this code. Cite the original paper for a result; do not imply that any listed
author or institution endorses this repository.
